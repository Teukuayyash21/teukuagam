NETWORK DEVICES

Perangkat penting

Perangkat jaringan memiliki peran masing-masing dalam menghubungkan dan meneruskan data.

⌘

Router

Meneruskan paket antarjaringan berdasarkan alamat IP dan tabel routing.

NETWORK LAYER
▤

Switch

Menghubungkan perangkat dalam LAN dan meneruskan frame berdasarkan MAC address.

DATA LINK LAYER
◉

Access Point

Menyediakan konektivitas nirkabel agar perangkat Wi-Fi dapat bergabung ke jaringan.

WIRELESS ACCESS
NETWORK TYPES

Jangkauan jaringan

Jenis jaringan dapat dibedakan berdasarkan cakupan dan kebutuhan penggunaannya.

PAN

Personal Area Network

Jaringan jarak dekat, misalnya ponsel terhubung ke earphone Bluetooth.

LAN

Local Area Network

Jaringan di area terbatas seperti rumah, laboratorium, atau kantor.

WAN

Wide Area Network

Jaringan dengan cakupan geografis luas yang menghubungkan banyak lokasi.
